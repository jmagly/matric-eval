# Preregistered evaluation studies

Study directories contain a validated machine-readable protocol, execution notes,
and the report source used for both site and PDF publication.

- [`qwen38-obliteration-2026-09`](qwen38-obliteration-2026-09/README.md): matched
  Qwen3.8 27B source, E03, and Pliny V3 refusal-intervention comparison.

Validate a protocol with `matric-eval validate-study <protocol.yaml>`. Executable
validation and all model runs must follow the host policy declared by that protocol.
