# matric-eval 2026.9.0

Release date: 2026-09-09 (UTC). Availability is established by a completed
[Gitea](https://git.integrolabs.net/roctinam/matric-eval/releases) or
[GitHub release](https://github.com/jmagly/matric-eval/releases), not by
this source file. No registry publication is enabled.

## Changes

- Adopt `YYYY.M.PATCH`, synchronizing Python, TypeScript and lockfile versions
  through one bump command. September's initial version is `2026.9.0`.
- Distribute verified release archives and evidence through Gitea and GitHub downloads.
  Tagged publication requires main ancestry and successful exact-commit CI;
  uploads remain draft until their bytes have been verified.
- Lock CI dependency setup and retain combined coverage, package, client and
  public benchmark source checks without repeating the entire unit suite as smoke.
- Include staged study preflight, durable owned-resource cleanup, accurate
  progress/diagnostics, independent suite scheduling, compatible result reuse,
  actual client/broker checks and bounded storage qualification.

## Compatibility

Python 3.11+ and Node.js 18+ remain required. The CalVer change does not change
result/protocol schema numbers, frozen study inputs or the authorization of
deferred suites. CalVer counters do not encode API compatibility; review the
supported contracts and pin the selected package version where needed.

## Installation and verification

Use [the release guide](https://github.com/jmagly/matric-eval/blob/v2026.9.0/docs/development/releasing.md) to download, verify and
install a wheel or TypeScript tarball. PyPI and npm registry publishing are
disabled. Historical `0.1.0` and `0.2.0` tags remain unchanged.

The candidate workflow must pass archive checks, SBOM/license/vulnerability
review and clean Python 3.11–3.14 consumer validation. The released bundle retains
those reports, exact source identity and `SHA256SUMS`. Failed validation does not
become a successful release merely because these notes exist.

## Dependency review

Click, GitPython and pypdf now require patched versions. Two known findings
remain under scoped reviews expiring on 2026-09-30: protobuf
`PYSEC-2026-1805` and NLTK `PYSEC-2026-3740`. The evaluated call paths do not
use the affected APIs with hostile inputs; these reviews do not establish that
the dependencies are generally free of vulnerabilities. See the exact exposure
assessments in [the vulnerability policy](https://github.com/jmagly/matric-eval/blob/v2026.9.0/release/vulnerability-policy.json).

The pinned IFEval Git dependency is absent from PyPI audit coverage. Its
[separate source review](https://github.com/jmagly/matric-eval/blob/v2026.9.0/release/source-reviews/instruction-following-eval.md)
is bound to the exact commit, installed files and NLTK version. It assumes trusted
benchmark metadata and bounded responses; downloaded NLTK resources are not
integrity-attested. Raw audit skips remain visible in the release evidence.
Dependency license interpretations and bundled component obligations are recorded
in [the license review](https://github.com/jmagly/matric-eval/blob/v2026.9.0/docs/development/license-review-2026.9.0.md).
