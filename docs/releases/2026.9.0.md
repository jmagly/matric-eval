## Changes

- Adopt `YYYY.M.PATCH`, synchronizing Python, TypeScript and lockfile versions
  through one bump command. September's initial version is `2026.9.0`.
- Distribute verified release archives and evidence through Gitea and GitHub downloads.
  Tagged publication requires main ancestry and successful exact-commit CI;
  uploads remain draft until their bytes have been verified.
- Lock CI dependency setup and retain combined coverage, package, client and
  public benchmark source checks without repeating the entire unit suite as smoke.
- Include staged study preflight, durable owned-resource cleanup, accurate
  progress/diagnostics, independent suite scheduling, compatible result reuse,
  actual client/broker checks and bounded storage qualification.

## Compatibility

Python 3.11+ and Node.js 18+ remain required. The CalVer change does not change
result/protocol schema numbers, frozen study inputs or the authorization of
deferred suites. CalVer counters do not encode API compatibility; review the
supported contracts and pin the selected package version where needed.

## Installation and verification

Use [the release guide](../development/releasing.md) to download, verify and
install a wheel or TypeScript tarball. PyPI and npm registry publishing are
disabled. Historical `0.1.0` and `0.2.0` tags remain unchanged.

The candidate workflow must pass archive checks, SBOM/license/vulnerability
review and clean Python 3.11–3.14 consumer validation. The released bundle retains
those reports, exact source identity and `SHA256SUMS`. Failed validation does not
become a successful release merely because these notes exist.
